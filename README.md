# 🎓 Student Management System

A modern and user-friendly **Student Management System** built with **FastAPI, HTML, CSS and JavaScript**.  
The application allows users to manage student records through a simple and responsive web interface.

🌐 **Live Demo:**  
https://student-management-system-z71u.onrender.com/

---

## 🚀 Features

- ➕ Add new student records
- 👨‍🎓 Manage student information
- 🔍 View student records
- ✏️ Update student details
- 🗑️ Delete student records
- 📊 Manage student marks and course information
- 📱 Responsive and user-friendly interface
- ⚡ FastAPI-powered backend
- 🌐 Deployed online using Render
- 🔄 GitHub-based automatic deployment
